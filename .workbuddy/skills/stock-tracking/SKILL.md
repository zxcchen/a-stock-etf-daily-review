## 执行流程

### Step 1：确认交易日
- 调用 `tdx_kline` 查 600160 近 3 根日线，确认最新日期是否为当日
- 非交易日告知用户后结束

### Step 2：并行拉取 K 线数据
- 对 6 只个股调用 `tdx_kline`，参数：`period="4", wantNum=6`
- setcode：深市=0，沪市=1

### Step 2.5：拉取技术指标（5 次 API 调用）

使用 `tdx_indicator_select`，按以下顺序分批查询：

**批次 A（MA+DIF）** — 分 2 次，每次 3 只：
```
"A B C MA5 MA10 MA20 MA60 MACD的DIF"
```
- 第 1 批：600160 + 002080 + 000920
- 第 2 批：603290 + 000063 + 002803

**批次 B（MACD完整）** — 1 次，全部 6 只：
```
"全部6只 MACD的DEA MACD柱"
```

**批次 C（KDJ）** — 1 次，全部 6 只：
```
"全部6只 KDJ的K D J"
```

**批次 D（RSI）** — 1 次，全部 6 只：
```
"全部6只 RSI1 RSI2"
```

**批次 E（BOLL中轨）** — 1 次，全部 6 只：
```
"全部6只 布林线BOLL中轨"
```

**⚠️ NLP 约束**：单次查询超过 4 种指标类型时 NLP 可能截断，因此按指标类型拆分；但单种指标类型可一次查全部 6 只。

### Step 3：逐只分析

每只个股分析维度：
1. **近5日OHLC表** — 日期/开盘/最高/最低/收盘/涨跌/成交额
2. **5日区间统计** — 最高/最低/累计涨跌
3. **支撑压力位** — 基于近期高低点判断
4. **技术指标** — 见下方信号解读表
5. **量能趋势** — 放量/缩量判断
6. **操作建议** — 持/买/卖/观望 + 具体价位

### Step 4：综合排名
按 5 日涨跌排序，标注优先关注/可关注/观望/回避。

### Step 5：输出报告
- 保存到 `a-stock-etf-daily-review/stock-tracking/YYYYMMDD.md`

## 技术指标信号解读

每只个股展示以下技术指标表格，并附带一句话信号判断：

| 指标 | 参数 | 看涨信号 | 看跌信号 | 中性/观望 |
|------|------|---------|---------|----------|
| **MA均线** | 5/10/20/60 | 多头排列(5>10>20>60) | 空头排列(5<10<20<60) | 均线缠绕 |
| **MACD** | DIF/DEA/柱 | DIF上穿DEA(金叉)、柱翻红 | DIF下穿DEA(死叉)、柱翻绿 | 走平收敛 |
| **KDJ** | K/D/J | K上穿D、J<20超卖区金叉 | K下穿D、J>100超买区死叉 | 中轴50附近震荡 |
| **RSI** | 6/12 | RSI6<20 超卖反弹 | RSI6>80 超买回调 | 40-60区间震荡 |
| **BOLL** | 中轨(20日均线) | 价格站回中轨、向上开口 | 价格跌破中轨、向下开口 | 沿中轨缩口震荡 |

### 信号综合等级

| 等级 | 条件 |
|------|------|
| **🔴 买入** | MA多头 + MACD金叉/柱翻红 + KDJ金叉 + RSI6从<20反弹 |
| **🟡 持有/观望** | 信号混杂，2正2负 |
| **🟢 卖出/回避** | MA空头 + MACD死叉/柱翻绿 + KDJ死叉 + RSI6>80下行 |

## 数据源

- 通达信 TDX MCP：
  - `tdx_kline`（日线 OHLCV）
  - `tdx_indicator_select`（MA/MACD/KDJ/RSI/BOLL）
- 代码与 setcode 必须匹配（已验证）

## 注意事项

- 盘中生成标注「盘中快照」；15:00后生成为「收盘版」
- 技术指标数据为当日最新值（盘中则随行情实时变化）
- 报告末尾附免责声明
